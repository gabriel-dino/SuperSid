# The game

Create a love2d lua game with a hero name Sid which is a sloth like Sid from Ice Age.

Generate the sloth image to resemble Sid from Ice Age and the image to have the style of Chrome Dino game
the dinosaur which appears in Chrome when there is no internet.

The game must be like SuperTux so that Sid the sloth walks from left to right and can go right to left also,
can jump with space and shoot with Alt key. Sid will shoot fire balls.

Sid must collect coins like in SuperTux. Sid is attacked by enemies like flying birds and walking monkeys.

Sid fires 5 shots but can find ammo.

# Levels

The game must have 10 levels and Sid plays them in order.

Sid wins when he gets to the end.

# Coins

Make a menu where Sid can buy stuff with coins:

- hats
- bullets
- special bullets
- guns that shoots at different speeds
- change color
- halloween style outfits
